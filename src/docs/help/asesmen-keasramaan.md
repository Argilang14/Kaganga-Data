---
title: Petunjuk
---

Pilih matev keasramaan terlebih dahulu, lalu lakukan penilaian pada masing-masing murid.

Gunakan tombol <kbd class="kbd">Download Template</kbd> untuk mengunduh template yang akan digunakan untuk penilaian keasramaan. Masing-masing mata evaluasi berbeda formatnya. Lalu gunakan tombol <kbd class="kbd">Import Nilai</kbd> untuk memasukkan kembali nilainya sekaligus.

Gunakan <kbd class="kbd">Template Massal</kbd> untuk mengisi seluruh mata evaluasi dan tujuan pembelajaran dalam satu file per kelas. Nilai dapat memakai skala 0-100 atau rubrik 1-4.

Masukkan kembali file tersebut melalui <kbd class="kbd">Import Massal</kbd>. Murid dicocokkan berdasarkan NISN, kemudian nama, dan data lama pada kolom yang diisi akan diperbarui.
