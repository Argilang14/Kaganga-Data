# Kaganga v2.2.4

Tanggal persiapan: 6 Oktober 2026.

## Perubahan

- Absensi Kegiatan menjadi Catat Absensi. Monitoring dan Rekap dikelompokkan dalam satu menu Monitoring & Rekap Absensi, dengan dua tab dan tautan lama tetap berlaku.
- Monitoring sekolah masuk/pulang, sholat lima waktu, makan dan apel malam menggunakan catatan tersimpan, penugasan murid dan semester aktif. Belum tercatat tidak otomatis dianggap alfa.
- Tampilan monitoring responsif untuk desktop, tablet dan HP; filter, pagination, detail murid, pilihan sumber kegiatan dan tema gelap tetap tersedia.
- Dashboard Absensi Hari Ini memakai sumber monitoring yang sama. Pembaruan manual/berkala berhenti saat halaman tersembunyi; gangguan koneksi mempertahankan data sebelumnya.
- Tanggal, kelas dan kegiatan Catat Absensi tidak kembali ke default setelah menyimpan satu murid, massal, menghapus status atau reload, termasuk pengiriman formulir tanpa JavaScript.
- Guru dapat mencatat Zuhur dan Asar (Ashar) untuk tanggal Senin-Jumat. Wali Asuh/Wali Asrama tetap dapat mencatat lima waktu setiap hari sesuai anak binaannya. Koreksi tanggal lama tetap memerlukan izin khusus.
- Hak menu guru, wali, Tim Dapur dan Waka Humas diperjelas. Tim Dapur hanya memperoleh kegiatan makan; akses pimpinan/operator dan pengecualian admin tetap mengikuti kebijakan yang sudah ada.
- Manajemen pengguna mendukung Tim Dapur dan pilihan Operator, termasuk pembuatan akun massal sesuai jenis pegawai. Profil pegawai sendiri dapat diperbarui tanpa membuka perubahan identitas resmi/jabatan.
- Pembatasan jenis dokumen cetak, ekspor, impor dan cakupan sekolah/murid tetap diperiksa di server, bukan hanya melalui tampilan tombol.
- Nama aplikasi, lisensi installer, versi runtime dan installer tetap Kaganga. Rilis stabil v2.2.4 disediakan untuk pemeriksaan pembaruan melalui GitHub Latest.

## Pemasangan dan Migrasi

1. Buat backup database pada PC server sekolah serta salin folder foto/lampiran sebelum memperbarui. Backup lokal pengembang tidak menggantikan backup PC sekolah.
2. Unduh `KagangaSetup-v2.2.4.exe` melalui Pengaturan > Cek Update atau halaman Releases. Tutup aplikasi lama sebelum memasang pada lokasi instalasi sebelumnya.
3. AppId dan folder data Kaganga tidak diganti. Pemasangan baru membawa database bersih, bukan database atau berkas sekolah pengembang. Penyesuaian kompatibilitas yang diperlukan tetap dijalankan saat startup.
4. Periksa daftar murid, role/jabatan akun, penugasan kelas/anak binaan, Catat Absensi, dua tab Monitoring/Rekap dan preview PDF setelah pemasangan.
5. Untuk rollback, pulihkan backup database dan foto/lampiran sebelum menggunakan installer lama. Jangan menghapus database untuk mengatasi kegagalan pembaruan.

Source terbaru tersedia pada branch utama repo. Clone melalui GitHub CLI:

```bash
gh repo clone Argilang14/Kaganga-Data
```

Tidak diperlukan clone ulang untuk pengguna installer. Database, backup, unggahan dan screenshot data sekolah tidak diunggah ke repo publik.

## Pengujian dan Batasan

- Seluruh 208 unit test lulus sebelum kenaikan versi, termasuk izin guru/wali, sholat, identitas murid, backup/restore, updater dan navigasi tab.
- Pengujian monitoring, role dan filter memakai SQLite salinan serta port QA terpisah. Port produksi 1206 dan PC server sekolah tidak dioperasikan.
- Uji runtime paket meliputi pemasangan baru dan upgrade pada salinan database. Pengujian runtime tidak menggantikan uji wizard installer pada PC/VM terpisah.
- Installer belum ditandatangani menggunakan sertifikat penerbit tepercaya; Windows dapat menampilkan peringatan.
- `pnpm check`: 0 error, 115 warning lama di 35 berkas. Build produksi adapter-node berhasil dan lint terarah pada kode monitoring/navigasi/QA paket bersih.
- Lint seluruh repo belum lolos: dokumen HTML lama `docs/keasramaan.html` dan `docs/rapor.html` gagal diparse, dan sejumlah berkas lama belum mengikuti format. Tidak dilakukan pemformatan/refaktor massal.
- Audit dependency staging melaporkan 12 temuan: 1 rendah, 2 sedang, 9 tinggi. Temuan ini belum diselesaikan; gunakan uji salinan data sebelum pemasangan massal atau akses internet, dan jadwalkan audit dependency terpisah.
- QA filter pada build final: 6 kelompok lulus, termasuk simpan native tanpa JavaScript. QA role: 12 kelompok lulus, termasuk input, QR, impor, profil, dokumen dan cakupan murid. Monitoring/navigasi: 14 kelompok lulus pada desktop/tablet/HP, tanpa error browser.
- Paket runtime v2.2.4 lulus skenario fresh dan upgrade pada salinan SQLite di port 5160/5161: migrasi, integritas, foreign key, jumlah data, 16 halaman operasional dan autentikasi. Database installer tidak berisi sekolah, kelas, murid, pegawai atau peserta ujian.

Setelah publikasi, endpoint GitHub Latest serta deteksi/unduhan updater v2.2.3 diperiksa menggunakan runtime lama dan folder data QA. Pengujian tidak menjalankan installer atau mengubah PC server sekolah.
