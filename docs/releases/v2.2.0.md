# Kaganga v2.2.0

Tanggal rilis: 28 September 2026

## Fitur utama

- Arsip murid dan alumni, riwayat kelas, audit aktivitas, pusat persetujuan, manajemen berkas, dan pusat notifikasi.
- Dashboard pimpinan, inventaris, pengumuman dan agenda, komunikasi terintegrasi, Portal Wali Murid berbasis akun, manajemen ruangan, rekomendasi jadwal, dan sesi ujian.
- Kartu peserta ujian serta penyempurnaan kartu absensi atau kartu pelajar dengan pratinjau PDF dan tata letak massal A4.
- Pemantauan kehadiran untuk sakit atau alfa berulang, izin pulang murid, tindak lanjut, dan PDF rekap absensi kegiatan.
- Fondasi operasional server, backup bertingkat, pemeriksaan kesehatan database, dan pengelolaan sesi perangkat.

## Penyempurnaan antarmuka

- Merapikan dashboard, Data Pegawai, Riwayat Pertumbuhan, Martikulasi, Presensi Pegawai, Rekap Kegiatan, dan halaman Cetak.
- Menambahkan dialog terpisah untuk impor Rekap Kegiatan dan pencatatan izin pulang.
- Mengelompokkan Portal Wali Murid, Komunikasi, serta Pengumuman dan Agenda di bawah menu Lain-lain.
- Memperbaiki tampilan responsif pada desktop, laptop, tablet, dan telepon genggam.

## Keamanan dan data

1. Hak akses fitur baru tersedia melalui Manajemen Pengguna dan tetap dibatasi per sekolah serta penugasan.
2. Foto dan lampiran disimpan di luar SQLite agar database tetap ringan.
3. Audit perubahan, snapshot dokumen, serta pemeriksaan foreign key membantu menjaga riwayat data.
4. Data sekolah tidak pernah disertakan dalam installer bersih.

## Catatan pembaruan

1. Installer mempertahankan `AppId` Kaganga sehingga pemasangan memperbarui instalasi yang sama.
2. Port aplikasi tetap `1206` dan data aktif tetap berada di `%LOCALAPPDATA%\Kaganga-data`.
3. Backup otomatis dibuat sebelum migrasi versi `2.2.0`.
4. Folder lampiran perlu disertakan ketika memindahkan server ke perangkat baru.
5. Portal wali tanpa login belum termasuk dalam rilis ini; Portal Wali Murid masih menggunakan akun yang dikelola sekolah.

## Validasi rilis

- Pemeriksaan Svelte dan TypeScript.
- Tes jadwal, keamanan database, tata kelola data, dokumen, PDF, dan fitur absensi.
- Pemeriksaan SQLite dan foreign key pada database kerja serta database installer bersih.
- Build produksi, staging Windows, dan startup paket sebelum publikasi.
