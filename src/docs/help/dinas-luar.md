# Dinas Luar

Dinas Luar digunakan pegawai untuk mengajukan perjalanan dan menyimpan bukti kegiatannya.

- Pengguna yang terhubung ke Data Pegawai mengajukan untuk dirinya sendiri; admin dapat memilih pegawai.
- Undangan PDF bersifat opsional dan dibatasi maksimal 10 MB.
- Admin dapat menyetujui atau menolak pengajuan. Persetujuan otomatis membentuk draft SPPD.
- Setelah disetujui, unggah maksimal satu PDF dan tiga foto bukti perjalanan.
- Bukti hanya dapat dibaca oleh pengguna pada sekolah yang sama.
- Status disetujui dan selesai terhubung dengan Presensi Pegawai sebagai Dinas Luar.
