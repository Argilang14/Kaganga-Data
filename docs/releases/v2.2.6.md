# Kaganga v2.2.6

Tanggal rilis: 11 Oktober 2026.

## Perbaikan Utama

- Input NPSN delapan digit di Form Sekolah dan Satuan Pendidikan diperbaiki. Angka nol awal dipertahankan dan isian jenjang lain yang belum disimpan tidak direset.
- Preview jadwal pelajaran dan kalender pendidikan memeriksa identitas satuan serta pegawai penandatangan sebelum membuat token PDF. Kesalahan seperti "Identitas satuan SMP belum diisi di Data Sekolah" ditampilkan langsung pada halaman cetak.
- Kop jadwal seluruh jenjang tetap memakai nama sekolah induk dari Form Sekolah. Cetak SRD/SRMP/SRMA memakai nama resmi satuan masing-masing. Pembaruan tidak mengisi NPSN perkiraan atau mengubah snapshot dokumen lama.
- Pemeriksaan identitas murid diperkuat untuk NISN kosong/placeholder/duplikat, UID bersama yang ambigu, serta snapshot arsip lama. Pemulihan identitas harus diperiksa admin; perubahan status satu murid tidak boleh memengaruhi murid lain.
- Arsip Murid & Alumni menyediakan hapus permanen untuk status Keluar Sekolah, khusus admin, dengan pratinjau dampak, konfirmasi nama dan alasan, backup terverifikasi sebelum transaksi, serta pengaman relasi dan dokumen. Tidak ada hapus massal; snapshot ujian tetap dipertahankan.
- Kartu absensi model QR saja menjadi portrait 94 x 123 mm, empat kartu pada A4. Desain memakai sampul baru dan QR murid yang sudah diterbitkan. Model foto+QR dan dua sisi tetap tersedia.
- Catat Absensi dan Rekap Absensi dirapikan dengan filter sejajar, tombol/dropdown, ringkasan berwarna, dan tabel responsif desktop/tablet/HP. Penyimpanan tetap mempertahankan pilihan tanggal, kelas, dan kegiatan; aturan impor/sinkronisasi dan hak akses tidak diperluas.

## Pemasangan

1. Backup database dan salin foto/lampiran dari PC server sekolah sebelum memperbarui. Backup atau pengujian pada komputer pengembang bukan pengganti backup PC sekolah.
2. Unduh `KagangaSetup-v2.2.6.exe` melalui Pengaturan > Cek Update atau halaman Releases. Tutup Kaganga lama dan pasang ke lokasi instalasi yang sama.
3. AppId installer, direktori Kaganga-data, dan port produksi tetap dipertahankan. Database awal paket bersih; pembaruan tidak mengganti database operasional dengan data pengembang.
4. Untuk sekolah terintegrasi, simpan nama resmi dan NPSN SD/SMP/SMA melalui Satuan Pendidikan sebelum mencetak per jenjang. NPSN induk bukan pengganti ketiga identitas satuan.
5. Periksa daftar murid, arsip, Catat Absensi, Rekap Absensi, preview jadwal seluruh jenjang/per jenjang, dan kartu absensi setelah pemasangan.
6. Hapus permanen hanya untuk data salah input yang memang sudah keluar dan telah diverifikasi. Riwayat/alumni yang sah sebaiknya tetap diarsipkan. Menghapus baris tidak otomatis mengecilkan berkas SQLite; backup juga memakai ruang disk.

Kode sumber tersedia pada branch utama:

```bash
gh repo clone Argilang14/Kaganga-Data
```

## Pengujian dan Batasan

- Build produksi dan pemeriksaan Svelte lulus: 0 error, 115 warning lama pada 35 file.
- Sebanyak 52 uji unit terarah lulus: identitas/lifecycle murid, kebijakan hapus permanen, kartu absensi, satuan pendidikan, aturan menu, dan logika jadwal.
- QA pada salinan database mencakup NPSN melalui browser, pemulihan/penghapusan murid dengan backup dan rollback, impor/ekspor, UI absensi desktop/tablet/HP, serta preview jadwal admin/Wakakur dan pesan identitas tidak lengkap.
- Pengujian runtime paket mencakup instalasi awal bersih dan migrasi salinan database lama, integritas SQLite, foreign key, autentikasi, serta halaman utama. Pengujian tidak mengoperasikan PC sekolah atau port produksi 1206.
- Sepuluh PDF jadwal admin/Wakakur lulus, termasuk per jenjang dan seluruh jenjang, portrait padat dan landscape multi-halaman, nama kop, serta penolakan identitas/penandatangan tidak valid. QR pada sembilan kartu absensi hasil rasterisasi dapat dibaca dan token aktif tidak berubah.
- Data murid, database, backup, unggahan, token, dan screenshot pengujian tidak diterbitkan ke repo atau paket installer.
- Installer belum ditandatangani dengan sertifikat penerbit tepercaya. Windows dapat menampilkan peringatan penerbit.
- ESLint terarah lulus pada modul perubahan lainnya; 17 temuan CetakSR sama dengan baseline v2.2.5. Tidak dilakukan pemformatan/refaktor massal pada rilis ini.
- Audit dependensi produksi melaporkan 12 kerentanan: 1 rendah, 2 sedang, dan 9 tinggi. Temuan PDF/browser/Excel belum seluruhnya diselesaikan; rilis ini tidak mengklaim bebas kerentanan dan tidak memperbarui dependensi besar tanpa pengujian kompatibilitas.
- Kasus database sekolah yang sudah terpengaruh identitas ambigu tidak otomatis dipulihkan. Perlu pemeriksaan admin dengan backup sekolah terbaru; jangan impor ulang seluruh murid sebagai langkah pemulihan.
- Pembatasan integrasi Dapodik SRT dan NIS yang sama antarjenjang dalam satu semester tetap mengikuti v2.2.5. Rilis ini tidak menambahkan pengiriman WhatsApp otomatis atau persetujuan sakit/izin.
