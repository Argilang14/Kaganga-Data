# Kaganga v2.3.5

Rilis 13 November 2026 memperbarui hak akses, leger Martikulasi, rekap absensi lintas bulan, dan kerapian dashboard.

## Perubahan

- Menu Kurikulum mendapat akses penuh untuk Waka Kurikulum, Admin, dan Kepala Sekolah. Input nilai Martikulasi tersedia bagi Waka Kesiswaan, Wali Kelas, serta Wali Asuh sesuai cakupan penugasan. Hak role lain tetap mengikuti aturan yang berlaku.
- Rekap Nilai Akademik menampilkan level Martikulasi di sebelah rata-rata intrakurikuler. Leger Excel memuat kelompok Martikulasi dengan subkelompok Akademik dan Asrama, serta delapan kolom: LIT, NUM, IPA, BING, PAPB, KEPM, KETR, dan KEMN. Nilai setiap aspek disajikan terpisah.
- Rekap Absensi Kegiatan memakai bulan awal dan bulan akhir. Indikator tindak lanjut dihitung untuk setiap bulan dalam rentang: sakit, izin, dan pulang lebih dari tiga hari, alfa mulai satu kali, serta presensi abnormal/belum tercatat sesuai ketentuan. Bulan berjalan dibatasi sampai hari ini. Catatan presensi historis tetap terbaca meski mendahului tanggal masuk hasil impor; hari tanpa catatan sebelum tanggal masuk tidak dihitung sebagai ketidakhadiran.
- Semua Murid dapat dibaca seluruh role; perubahan data tersedia bagi Admin, Kepala Sekolah, Operator, dan Waka Kurikulum. Murid Kelas terbatas pada empat role tersebut dan Wali Kelas yang ditugaskan. Murid Asrama tersedia bagi Admin, Kepala Sekolah, Operator, Wali Asrama, dan Wali Asuh; Wali Asuh hanya melihat anak binaannya dan tidak mengubah data murid.
- Murid Pasif dapat dibaca seluruh role. Perubahan data tersedia bagi Admin, Kepala Sekolah, Operator, Waka Kurikulum, Wali Kelas, dan Wali Asrama sesuai tindakan yang diizinkan. Pemeriksaan server juga melindungi perubahan foto, profil, dan tambah/hapus data kesehatan.
- Pilihan asrama/periode berulang di Input Nilai Keasramaan, Catatan Wali Asrama, dan Rekap Nilai Keasramaan dihapus; konteks mengikuti navbar dan Data Rapor.
- Dashboard mempertahankan grafik kehadiran dan menghapus Rincian 7 hari. Kartu pendamping tersusun berpasangan saat ruang cukup; progres nilai memakai dua kolom di desktop dan kartu bawah sejajar. Warna, isi, dan fungsi yang ada dipertahankan.

## Panduan pembaruan

1. Cadangkan database beserta foto, lampiran, profil privat, dan arsip PDF pada PC server.
2. Hentikan aplikasi server, pasang installer v2.3.5 pada lokasi yang sama, lalu jalankan kembali.
3. Periksa role akun serta penugasan Wali Kelas, Wali Asrama, Wali Asuh, kelas, dan mata pelajaran. Akun dengan beberapa role memperoleh gabungan akses yang diizinkan.
4. Periksa contoh leger Excel dan Rekap Absensi Kegiatan untuk rentang beberapa bulan.

Installer memakai database awal kosong untuk instalasi baru; data operasional sekolah tidak disertakan dalam paket. Password tetap disimpan sebagai hash satu arah. Fitur menampilkan password belum diterapkan dalam rilis ini.

## Validasi dan batasan

- Seluruh 405 tes unit lulus. `pnpm check` menghasilkan 0 galat dan 119 peringatan yang sudah ada; build produksi berhasil.
- Tiga pengujian integrasi pada database salinan lulus: registri/penempatan/riwayat murid dan pembatasan role; rekap izin/absensi serta PDF lintas bulan; akses Martikulasi dan leger XLSX yang dibuka ulang untuk memeriksa nilai, rumus, dan merge.
- Dashboard diperiksa pada lebar 320–1920 px, termasuk mode gelap, data kosong, fokus keyboard, dan dialog absensi. Pengujian HTTP dengan 13 jenis akun memverifikasi akses daftar/detail murid serta penolakan perubahan tanpa izin.
- Lint pada 49 berkas kode yang berubah tidak menambah temuan dibanding HEAD; berkas baru lolos pemeriksaan format. Lint global masih terhenti pada format repositori serta sintaks dokumen HTML lama `docs/keasramaan.html` dan `docs/rapor.html` yang tidak diubah.
- Paket Windows lulus uji pemasangan baru dan pembaruan dari database salinan: startup, migrasi, integritas, relasi, autentikasi, halaman operasional terkait, template CSV 67 kolom, serta konteks cetak. Jumlah data sekolah dipertahankan setelah migrasi.
- Seluruh 2.043 berkas build dan aset statis pada staging cocok dengan sumber melalui SHA256. Database awal installer tidak memuat sekolah, pegawai, kelas, murid, atau mata pelajaran.

Installer belum ditandatangani sertifikat penerbit tepercaya. Pengujian dilakukan pada database salinan; pemasangan pada server sekolah, kamera, dan cetak fisik perlu diperiksa pada perangkat tujuan.
