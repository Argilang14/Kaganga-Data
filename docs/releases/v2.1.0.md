# Kaganga v2.1.0

Tanggal rilis: 4 September 2026

## Ringkasan perubahan

- Menambahkan Buku Tamu digital dengan tautan tamu, tanda tangan, dan pemisahan data per sekolah.
- Menambahkan Presensi Pegawai beserta rekap dan dokumen cetaknya.
- Menambahkan sinkronisasi Dapodik yang tervalidasi dan dokumentasi penggunaannya.
- Menambahkan bantuan AI opsional untuk menyusun Tujuan Pembelajaran tanpa mengubah data secara otomatis.
- Menyempurnakan Surat Menyurat untuk SPPD dan Dinas Luar beserta lampirannya.
- Menambahkan asesmen Martikulasi serta dokumen SK Tim, Raport Hasil, dan STTM dengan snapshot dokumen.
- Menyeragamkan kop Jadwal Pelajaran, Kalender Pendidikan, Jurnal Mengajar, dan dokumen Martikulasi berdasarkan Data Sekolah.
- Menyempurnakan presensi, keamanan login, izin pengguna, bantuan kontekstual, serta tampilan menu.

## Catatan migrasi dari v2.0.6

1. Installer mempertahankan `AppId` rilis sebelumnya sehingga pembaruan tetap memakai instalasi Kaganga yang sama.
2. Port aplikasi tetap `1206` dan data aktif tetap berada di `%LOCALAPPDATA%\Kaganga-data`.
3. Starter membuat backup database sebelum migrasi pertama versi `2.1.0`.
4. Tabel dan kolom baru dibuat secara idempoten tanpa menghapus data sekolah yang telah ada.
5. Direktori lama `%LOCALAPPDATA%\Rapkumer-data` hanya digunakan sebagai sumber migrasi bila database Kaganga belum tersedia.
6. Bila pembaruan gagal, tutup Kaganga dan pulihkan database dari backup pra-rilis atau backup otomatis sebelum versi `2.1.0`.

## Validasi rilis

- Database produksi telah dibackup dan lolos `PRAGMA integrity_check` serta `foreign_key_check`.
- Seluruh 68 unit test lulus; pengujian salinan database jadwal, pegawai, dan keamanan database juga lulus.
- `pnpm check` selesai tanpa error dan build produksi berhasil.
- Database awal installer bersih dari data sekolah, pegawai, kelas, murid, dan mata pelajaran.
- Runtime paket Windows pada instalasi bersih mengembalikan HTTP 200 di port uji 5152.
- Jalur pembaruan diuji terhadap salinan database produksi: 2 sekolah, 98 pegawai, 20 kelas, 254 murid, 260 mata pelajaran, dan akun pengguna tetap utuh.
- Setelah pembaruan uji, integritas database tetap `ok`, tanpa pelanggaran foreign key, dan tabel fitur baru tersedia.
- Port produksi 1206 tidak dijalankan atau diubah selama pengujian rilis.
