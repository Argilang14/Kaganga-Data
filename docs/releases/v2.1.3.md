# Kaganga v2.1.3

Tanggal rilis: 6 September 2026

## Ringkasan perubahan

- Merapikan alur SPPD, Dinas Luar, Buku Tamu, dan Presensi Pegawai.
- Menambahkan pilihan latar cetak untuk Jurnal Mengajar serta dokumen Martikulasi.
- Menyempurnakan input nilai Martikulasi dan level penempatan Dasar, Madya, atau Mahir.
- Memperbarui data intrakurikuler, impor-ekspor mata pelajaran, dan pembatasan akses berdasarkan penugasan.
- Menyusun ulang Pengaturan serta memperkuat keamanan akun dan manajemen izin pengguna.
- Menambahkan drag-and-drop sentuh pada Jadwal Pelajaran dan pengurutan mata pelajaran.

## Catatan migrasi dari v2.1.0

1. Installer mempertahankan `AppId` rilis sebelumnya sehingga pembaruan memakai instalasi Kaganga yang sama.
2. Port aplikasi tetap `1206` dan data aktif tetap berada di `%LOCALAPPDATA%\Kaganga-data`.
3. Starter membuat backup database sebelum migrasi pertama versi `2.1.3`.
4. Penambahan tabel dan kolom dijalankan secara idempoten tanpa menghapus data lama.
5. Direktori `%LOCALAPPDATA%\Rapkumer-data` hanya digunakan sebagai sumber migrasi jika database Kaganga belum tersedia.
6. Jika pembaruan gagal, tutup Kaganga lalu pulihkan backup otomatis sebelum versi `2.1.3`.

## Validasi rilis

- 77 unit test pada 23 berkas lulus tanpa kegagalan.
- `pnpm check` selesai dengan 0 error; 105 peringatan lama tetap tercatat dan tidak menghalangi build.
- Pemeriksaan basis data jadwal dan fondasi pegawai lulus, termasuk `quick_check` dan foreign key.
- Database bawaan installer sehat dan bersih: hanya satu akun admin awal tanpa data sekolah, pegawai, kelas, murid, atau mata pelajaran.
- Simulasi migrasi pada salinan database produksi selesai dengan `quick_check=ok`, tanpa foreign key rusak, dan mempertahankan 2 sekolah, 98 pegawai, 20 kelas, serta 254 murid.
- Build produksi dan kompilasi installer Windows berhasil.
- Paket produksi berhasil diuji pada `http://127.0.0.1:5152/login` dengan respons HTTP 200.
