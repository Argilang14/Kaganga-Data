# Kaganga v2.3.0

Tanggal rilis: 29 Oktober 2026.

## Perubahan utama

- Dashboard memakai grafik batang kehadiran tujuh hari. Jadwal hari ini mengikuti kelas aktif dan penugasan akun, tanpa membuka jadwal kelas di luar akses pengguna.
- Absensi Hari Ini menambahkan Asrama, label Berangkat Sekolah, serta tombol Sakit, Izin, Alfa, Izin Pulang, dan Belum Tercatat. Daftar murid memakai data Monitoring kegiatan masing-masing; belum tercatat tidak dianggap alfa. Daftar Sekolah mendukung pagination.
- Profil Pegawai Saya dirapikan: ringkasan identitas, tab biodata/pendidikan/sertifikasi/berkas, kolom form adaptif, tabel dengan scroll lokal, serta pintasan jumlah data. Hak akses profil sendiri dan validasi tetap dipertahankan.
- Pengasuhan & Asrama mengikuti susunan halaman dan tabel yang lebih seragam dengan Jurnal Mengajar. Akses catatan pribadi tetap mengikuti penugasan dan sekolah.
- Navigasi HP menyediakan dock dan menu lengkap sesuai izin akun. Sidebar, pencarian, dan favorit memakai kebijakan menu yang sama; pintasan terlarang tidak ditampilkan.
- Impor nilai dan perubahan bobot sumatif diperkuat dengan validasi serta transaksi. Nilai nol dibedakan dari isian kosong; identitas ambigu dan nilai di luar rentang ditolak.
- Pemulihan database menunggu pekerjaan yang sedang berjalan, menolak pemulihan bersamaan, dan mempertahankan kondisi tertutup bila proses pemulihan gagal. Deployment tetap memakai satu proses server utama.
- Cetak rapor dan piagam mendukung opsi tanda tangan kepala sekolah. Opsi bawaan tetap mati; tanda tangan wali kelas tidak dipinjam dari pegawai lain.

## Pemasangan

1. Buat backup database dan salin foto/lampiran dari PC server sekolah sebelum memperbarui. Backup komputer pengembang bukan pengganti backup sekolah.
2. Unduh `KagangaSetup-v2.3.0.exe` melalui Pengaturan > Cek Update atau halaman Releases. Tutup aplikasi lama dan pasang ke lokasi instalasi yang sama.
3. Installer mempertahankan AppId, port produksi 1206, dan direktori data Kaganga-data. Database paket merupakan database awal kosong; jangan mengganti database operasional dengan database paket.
4. Setelah pembaruan, periksa login, daftar murid, jadwal kelas aktif, Monitoring, profil pegawai, dan pratinjau PDF. Muat ulang browser client bila masih menampilkan halaman lama.
5. Akun hanya dapat membuka Profil Pegawai Saya setelah ditautkan ke Data Pegawai melalui Manajemen Pengguna.

## Batasan

- Tidak menambahkan sinkronisasi SIAP SR, integrasi WhatsApp otomatis, atau perubahan penugasan pengasuhan.
- Grafik menggunakan daftar murid aktif dalam cakupan saat ini, bukan rekonstruksi jumlah murid historis.
- Data operasional, foto pribadi, token, konfigurasi lokal, dan screenshot QA tidak disertakan di GitHub atau installer.
- Installer belum ditandatangani sertifikat penerbit tepercaya; Windows dapat menampilkan peringatan penerbit.
- Pemeriksaan Svelte masih melaporkan 116 warning. ESLint pada berkas perubahan melaporkan 28 temuan lama, tanpa tambahan dibanding baseline. Instalasi dependensi produksi melaporkan 15 kerentanan (1 rendah, 3 sedang, 11 tinggi); perbaikan dependensi tersebut belum termasuk rilis ini.
- Uji otomatis memakai database salinan. Pemasangan pada PC sekolah, perangkat kamera, jaringan sekolah, dan cetak fisik tetap perlu diperiksa operator.

## Pengujian rilis

- Build produksi dan kompilasi installer Inno Setup berhasil.
- Seluruh 340 tes unit lulus. Pemeriksaan Svelte: 0 error.
- Regresi impor nilai, transaksi bobot, identitas ambigu, dan opsi tanda tangan lulus pada database salinan.
- QA dashboard, pengasuhan, dan profil pegawai lulus, termasuk akses lintas akun/sekolah, keyboard, mode gelap, dan viewport 320-1920px.
- Empat template cetak diuji dengan tanda tangan sintetis: posisi nama dan tinggi halaman tetap.
- Runtime paket lulus skenario pemasangan baru dan upgrade: startup, migrasi, login, jumlah data tetap, integrity check, dan foreign key check.
- Pemulihan database salinan lulus, dengan 114 tabel dan 0 pelanggaran foreign key. Database awal dalam installer memuat 0 murid.
- Uji ini tidak menjalankan installer pada PC sekolah. Backup sekolah dan pemeriksaan operator setelah pemasangan tetap diperlukan.
