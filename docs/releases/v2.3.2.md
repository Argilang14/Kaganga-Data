# Kaganga v2.3.2

Tanggal rilis: 4 November 2026.

## Perubahan

- Peserta Didik dipisahkan menjadi Semua Murid, Murid Kelas, Data Murid Asrama, dan Murid Pasif. Riwayat kelas/asrama serta status pindah, keluar, dan alumni tersedia melalui Semua Murid.
- Murid tanpa kelas atau tanpa asrama muncul pada Murid Pasif. Penempatan kelas dan asrama dapat mengambil murid dari daftar tersebut. Perubahan status mempertahankan riwayat penempatan.
- Data Asrama memakai penugasan wali dari Data Pegawai. Daftar murid asrama menampilkan Wali Asuh serta aksi Detail dan Jadikan Pasif sesuai hak akses.
- Mata evaluasi, input nilai, catatan wali asrama, rekap, dan cetak rapor asrama mengikuti penempatan asrama dan semester. Wali Asuh menilai seluruh mata evaluasi anak binaannya; perpindahan kelas tidak memindahkan nilai asrama.
- Manajemen Pengguna memakai beberapa role pada satu akun. Pilihan Jabatan Akses digabung ke role. Hak Wali Kelas mengikuti penugasan Data Kelas aktif; akses kelas lain tetap mengikuti penugasan mapel dan kelas mengajar.
- Rekap bulanan menggabungkan catatan izin dan kepulangan guru dengan bukti absensi serta verifikasi keamanan. Indikator tindak lanjut mencatat izin, sakit, dan pulang lebih dari tiga hari dalam sebulan, alfa sedikitnya satu hari, serta akumulasi belum tercatat sesuai ketentuan rekap.
- Status Pulang manual pada dialog penyelesaian scan dapat dicatat guru sesuai kewenangannya. Catatan absensi tersebut terpisah dari persetujuan izin resmi dan konfirmasi keamanan.
- PDF Martikulasi memperluas tabel akademik setelah kolom catatan dihapus, memakai judul Capaian Akhir pada tabel keasramaan, meratakan angka capaian ke tengah, dan menyesuaikan tanda tangan Wali Kelas dari Data Kelas.
- Tampilan input nilai, mata evaluasi, catatan, rekap, dan cetak rapor asrama mempertahankan model sebelumnya dengan pengelompokan berdasarkan asrama.

## Pembaruan server sekolah

1. Cadangkan database PC server beserta folder foto, lampiran, dan PDF arsip.
2. Tutup aplikasi lama, unduh `KagangaSetup-v2.3.2.exe`, lalu pasang pada lokasi instalasi yang sama. AppId, port produksi 1206, dan direktori data Kaganga-data dipertahankan.
3. Periksa hasil pemetaan role akun lama dan hubungan akun dengan pegawai aktif. Penugasan wali kelas, wali asrama, serta wali asuh perlu sesuai Data Kelas, Data Asrama, dan anak binaannya.
4. Pilih asrama dan semester pada penilaian keasramaan. Data nilai lama berbasis kelas dipertahankan sebagai riwayat; pemetaan susunan evaluasi dilakukan secara eksplisit, tanpa menyalin nilai ke penempatan baru.
5. Periksa jumlah murid, pegawai, nilai, penempatan, akses akun, rekap absensi, dan pratinjau rapor setelah pembaruan.

## Batasan

- Penggabungan menu Riwayat Rapor ke Cetak Rapor belum termasuk rilis ini. Rencana dicatat pada [issue #7](https://github.com/Argilang14/Kaganga-Data/issues/7).
- PDF final asrama masih memakai riwayat kelas yang tersedia. Murid tanpa riwayat kelas dapat mencetak PDF asrama langsung; formulir arsip final khusus penempatan belum tersedia.
- Data operasional sekolah, foto, lampiran, konfigurasi lokal, dan kredensial pengujian tidak disertakan dalam paket atau repositori.
- Installer belum ditandatangani sertifikat penerbit tepercaya. Windows dapat menampilkan peringatan penerbit.
- Instalasi dependensi produksi melaporkan 22 temuan keamanan npm: 1 rendah, 10 sedang, dan 11 tinggi. Pembaruan dependensi tersebut belum termasuk rilis ini.
- Pemasangan GUI pada PC sekolah, kamera, dan cetak fisik perlu diperiksa operator.

## Validasi rilis

- Seluruh 397 tes unit lulus. Pemeriksaan Svelte menghasilkan 0 galat dan 119 peringatan; build produksi berhasil.
- Lima skrip integrasi lulus pada database salinan: penempatan/status murid, role/penugasan akun, penilaian keasramaan, rekap izin/kepulangan bulanan, dan PDF rapor sekolah/asrama. PDF langsung dan PDF melalui token menghasilkan HTTP 200.
- Runtime paket Windows lulus untuk instalasi baru dan pembaruan dari salinan database lama sebelum migrasi kelas opsional, role, dan evaluasi asrama. Pemeriksaan mencakup startup, migrasi, login, halaman peserta didik/keasramaan/cetak, integrity check, foreign key check, dan jumlah data yang dipertahankan.
- Database dalam paket hanya berisi akun admin awal; tabel operasional kosong dan pemeriksaan relasi berhasil. Database sekolah tidak digunakan sebagai database awal installer.
- Lint global masih terhenti pada sintaks dua dokumen HTML lama dan temuan format repositori. Pemeriksaan ESLint pada cakupan perubahan menyisakan 29 temuan yang juga terdeteksi pada sumber v2.3.1; file rilis dan skrip integrasi keasramaan lulus pemeriksaan terfokus. Pemeriksaan whitespace perubahan Git lulus.
