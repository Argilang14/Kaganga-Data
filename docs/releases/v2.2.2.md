# Kaganga v2.2.2

Tanggal rilis: 3 Oktober 2026

## Perubahan utama

- Menu Cetak > Cetak Dokumen > Kartu Ujian Meja.
- Delapan kartu landscape 94 x 62 mm per A4 portrait, dua kolom dan empat baris, dengan jarak potong.
- Kop sekolah mengikuti data sekolah aktif; identitas peserta mengikuti snapshot sesi ujian.
- Filter sesi, kelas, dan ruang; PDF ditampilkan pada preview sebelum diunduh.
- Akun LMS ON/OFF, bawaan OFF untuk ujian berbasis kertas.
- TTD Kepsek ON/OFF khusus kartu meja, bawaan ON. Saat OFF seluruh blok tanda tangan disembunyikan, termasuk tempat/tanggal, jabatan, nama, dan NIP.
- Preview dibersihkan saat pilihan berubah. Kontrol tidak dapat diubah saat PDF sedang dibuat.
- Kartu ujian biasa tetap empat kartu 94 x 123 mm per A4, termasuk QR absensi dan tanda tangan yang sudah tersedia.

## Pemasangan dan data

1. Pada PC server sekolah, buat backup database dan salin folder foto/lampiran ke tempat aman.
2. Tutup aplikasi Kaganga lama sebelum menjalankan installer.
3. Pasang KagangaSetup-v2.2.2.exe pada lokasi aplikasi sebelumnya.
4. Buka Kaganga, pilih Cetak Dokumen, lalu Kartu Ujian Meja dan sesi ujian yang akan dicetak.
5. Pilih kelas/ruang, Akun LMS, dan TTD Kepsek, kemudian buat preview PDF.
6. Cetak pada kertas A4 dengan skala 100% / Actual Size, bukan Fit to Page; uji satu lembar sebelum mencetak massal.

Tidak ada migrasi database baru untuk fitur kartu meja. AppId, nama dan lisensi Kaganga, port 1206, lokasi data Kaganga-data, serta nomor peserta tersimpan tetap dipertahankan. Installer menggunakan database bersih, bukan data sekolah pengembang. Proses rilis tidak memasang pembaruan pada server produksi.

Pengujian memakai salinan database dan port terisolasi, bukan database produksi. Pengujian paket runtime bukan pengujian wizard installer nyata di PC/VM terpisah. Backup lokal dibuat sebelum rilis; backup PC sekolah tetap harus dibuat langsung pada perangkat tersebut sebelum pembaruan dipasang.

## Masalah yang masih terbuka

- Audit menemukan bahwa NISN placeholder/duplikat seperti 000 dapat membuat identitas lifecycle beberapa murid tergabung. Setelah satu murid dihapus, murid lain dapat tersembunyi dari daftar walaupun masih tersedia dalam ekspor. Rilis ini tidak memperbaiki masalah tersebut dan tidak memulihkan data PC sekolah secara otomatis. Jangan menghapus murid lagi atau mengimpor ulang Excel untuk memulihkan daftar kosong sebelum backup dan perbaikan khusus dilakukan.
- Masalah format lama dan parsing pada dokumen contoh dapat menyebabkan pnpm lint penuh belum lulus; tidak dilakukan perombakan berkas di luar lingkup rilis.
- Temuan dependensi PDF/browser/Excel belum seluruhnya selesai; jumlah temuan dicatat pada bagian validasi.
- Installer belum ditandatangani dengan sertifikat code-signing tepercaya sehingga Windows dapat menampilkan peringatan penerbit.
