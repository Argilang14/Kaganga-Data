# Kaganga v2.2.3

Tanggal persiapan: 4 Oktober 2026.

## Perbaikan pembaruan aplikasi

- Nomor versi aplikasi, build produksi, paket runtime, installer, dan tag GitHub diselaraskan menjadi 2.2.3.
- Pembanding versi memakai pustaka semver. Beta/rc berada sebelum versi stabil dengan basis sama; metadata build tidak memicu pembaruan palsu.
- Versi rilis yang tidak valid tidak ditawarkan sebagai pembaruan.
- Respons pemeriksaan pembaruan memakai Cache-Control: no-store.
- Rilis ini diterbitkan sebagai Latest, bukan draft atau prerelease. Sistem versi lama membaca endpoint GitHub releases/latest yang sama, sehingga 2.2.3 dapat dikenali dari 2.2.2 maupun 2.2.2-beta.1.
- Seluruh perbaikan identitas murid, hak akses, akun massal, absensi, ringkasan WhatsApp, dan penggabungan format kartu ujian dari Beta 1 ikut disertakan. Lihat [catatan Beta 1](v2.2.2-beta.1.md).

## Pemasangan dan data

1. Buat backup database pada PC server sekolah dan salin folder foto/lampiran. Backup laptop pengembang tidak menggantikan backup PC sekolah.
2. Pada aplikasi terpasang, buka Pengaturan, periksa pembaruan, lalu pastikan versi yang ditawarkan 2.2.3 dan nama berkas KagangaSetup-v2.2.3.exe.
3. Jika pemeriksaan belum menampilkan rilis baru, tutup dan buka kembali popup pembaruan atau unduh installer langsung dari halaman Releases. Periksa juga koneksi internet dan izin pemeriksaan pembaruan akun tersebut.
4. Tutup aplikasi lama sebelum memasang installer pada lokasi sebelumnya. Nama Kaganga, AppId, dan folder data tetap sama.
5. Uji daftar murid, izin pengguna, absensi, serta preview PDF setelah pemasangan. Rilis ini tidak memerlukan perubahan skema baru dibanding Beta 1; dari v2.2.2, penyesuaian identitas/akses yang sudah disiapkan tetap dijalankan saat startup.
6. Pulihkan backup database dan berkas sebelum upgrade jika rollback diperlukan; jangan sekadar menjalankan versi lama terhadap database yang sudah dimigrasi.

Installer membawa database bersih untuk pemasangan baru, bukan data sekolah pengembang. PC sekolah dan port 1206 tidak dioperasikan dalam proses build atau QA ini. Rilis lama tetap dipertahankan.

## Batasan

- Paket belum ditandatangani dengan sertifikat penerbit tepercaya; Windows dapat menampilkan peringatan.
- Audit dependency runtime saat staging masih melaporkan 11 temuan (2 sedang, 9 tinggi). Temuan keamanan serta format/lint lama tidak hilang hanya karena nomor versi dinaikkan. Audit dependensi harus ditindaklanjuti terpisah; gunakan uji salinan data sebelum pemasangan massal atau akses internet.
- QA paket runtime bukan pengujian wizard installer pada PC/VM terpisah.
- Branch rilis dan tag diperbarui. Perubahan branch utama main tetap memerlukan persetujuan eksplisit tersendiri.

## Validasi

- Seluruh 169 unit test lulus, termasuk perbandingan versi stabil/beta/rc, angka versi, metadata build, dan input versi tidak valid.
- pnpm check: 0 error, 115 peringatan lama pada 35 berkas. Build produksi adapter-node berhasil.
- Database installer: data sekolah, kelas, murid, pegawai, dan peserta ujian kosong; pemeriksaan SQLite sehat dan tidak ada pelanggaran foreign key. Tabel tambahan disiapkan saat startup.
- Uji runtime paket pada database salinan untuk pemasangan baru dan upgrade lulus: jumlah data tetap, migrasi startup, integrity, foreign key, 13 halaman operasional, autentikasi, penggantian password awal, dan pemeriksaan updater.
- Pemeriksaan updater terautentikasi mengembalikan versi runtime 2.2.3 serta Cache-Control: no-store. Permintaan anonim diarahkan ke login, bukan memperoleh metadata pembaruan.
- QA PDF dan UI kartu ujian lulus: pagination, filter, nama file, isolasi sekolah, tautan lama, kedua format, tombol hijau/netral, desktop/tablet/mobile, nama panjang, ukuran kartu meja, dan tanda tangan tidak tumpang tindih.

Setelah publikasi, verifikasi endpoint GitHub Latest, ukuran dan digest aset installer, serta pemeriksaan dan unduhan updater dari build lama dilakukan tanpa menjalankan installer atau menyentuh PC server sekolah.
