# Kaganga v2.1.7

Tanggal rilis: 15 September 2026

## Ringkasan perubahan

- Menambahkan generator RPM dan lampiran pembelajaran berbantuan AI dengan pratinjau dan ekspor PDF.
- Menyusun ulang Cetak Dokumen dan Cetak Raport sesuai jenis sekolah serta menambahkan pratinjau Buku Tamu Digital.
- Menambahkan ringkasan absensi harian dan kelengkapan data pada dashboard.
- Memperkuat izin menu, ekspor, dan akses kelas berdasarkan peran serta penugasan pengguna.
- Merapikan Presensi Pegawai dan menampilkan jenis pegawai secara konsisten.
- Menyeragamkan nama berkas PDF agar mudah dikenali setelah diunduh.
- Memperkuat backup dan pemulihan SQLite dengan validasi database, transaksi aman, dan rollback ketika impor gagal.
- Menaikkan batas impor backup menjadi 512 MB.

## Catatan migrasi

1. Installer mempertahankan `AppId` rilis sebelumnya dan memperbarui instalasi Kaganga yang sama.
2. Port aplikasi tetap `1206` dan data aktif tetap berada di `%LOCALAPPDATA%\Kaganga-data`.
3. Starter mempertahankan mekanisme backup sebelum migrasi versi aplikasi.
4. Database lama divalidasi dan dipulihkan secara transaksional tanpa menghapus data pengguna.
5. Jika pembaruan gagal, tutup Kaganga dan pulihkan backup terakhir melalui menu Pengaturan.

## Validasi rilis

- 22 tes regresi terpilih lulus tanpa kegagalan, termasuk backup, pemulihan, izin menu, ekspor, dashboard, dan nama PDF.
- `svelte-check` selesai dengan 0 error; 106 peringatan lama tidak menghalangi build.
- Build produksi SvelteKit berhasil.
- Kompilasi installer Windows dengan Inno Setup berhasil.
