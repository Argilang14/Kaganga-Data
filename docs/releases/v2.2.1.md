# Kaganga v2.2.1

Tanggal rilis: 3 Oktober 2026

## Perubahan utama

- Jabatan Akses pengguna untuk Kepala Sekolah, Waka Kesiswaan, Kurikulum, Sarana Prasarana, Keasramaan, dan Operator.
- Akses operasional lintas kelas sesuai jabatan; pengaturan sistem, manajemen pengguna, dan backup tetap khusus admin.
- Popup wajib ganti kata sandi saat login pertama, validasi kata sandi, serta pembaruan sesi setelah sandi diganti.
- Admin bawaan instalasi baru wajib mengganti sandi; sandi akun lama tidak direset oleh migrasi.
- Mencegah putaran pengalihan login pertama ketika data sekolah belum dibuat.
- Override keamanan js-yaml 4.3.2 dan qs 6.16.0.
- Kartu ujian 94 x 123 mm, empat kartu per A4 portrait, font identitas dan tanda tangan lebih besar, tanpa baris NIS.
- QR Absensi ON/OFF dan Akun LMS ON/OFF; akun LMS secara bawaan OFF untuk ujian berbasis kertas.
- Nomor peserta NPSN + urutan peserta lintas kelas, validasi NPSN delapan digit, serta Nomori Ulang berdasarkan urutan penambahan kelas.

## Migrasi dan pemasangan

1. Buat backup database dan salin folder foto/lampiran ke tempat aman.
2. Tutup aplikasi Kaganga lama sebelum menjalankan installer.
3. Pasang KagangaSetup-v2.2.1.exe pada lokasi aplikasi sebelumnya.
4. Buka Kaganga; proses startup mempertahankan database pengguna dan menjalankan migrasi aditif.
5. Admin dapat mengatur Jabatan Akses di Manajemen Pengguna. Akun lama tidak otomatis diberi jabatan.
6. Untuk nomor ujian lama, gunakan Nomori Ulang hanya setelah memastikan kartu lama boleh diganti, lalu cetak ulang kartu.

AppId, port 1206, lokasi data Kaganga-data, dan lisensi Kaganga tetap dipertahankan. Kolom jabatan_akses bersifat opsional dan tidak menghapus penugasan kelas atau mata pelajaran. QR absensi tetap memakai token murid yang sudah ada.

## Validasi rilis

- Seluruh 131 unit test lulus.
- pnpm check: 0 error, 115 peringatan yang sudah ada.
- Build produksi berhasil.
- QA jabatan akses dan login pertama lulus, termasuk validasi sandi, sesi baru, dan pencabutan sesi lama.
- QA penomoran ujian, PDF Akun LMS ON/OFF, QR, ukuran kartu, serta kontrol preview desktop/mobile lulus.
- Paket runtime instalasi bersih dan pembaruan dari salinan database aplikasi v2.2.0 lulus pada port QA 5160/5161; jumlah data sekolah dipertahankan, integrity_check OK, dan foreign_key_check bersih.
- Server pengembangan port 5152 memberi HTTP 200. Aplikasi terpasang pada port 1206 tidak dioperasikan atau diperbarui otomatis oleh proses rilis ini.

Pengujian paket dilakukan secara terisolasi. Wizard installer belum diuji melalui pemasangan nyata di PC/VM terpisah; instalasi produksi tidak digunakan sebagai lokasi QA.

## Catatan yang masih terbuka

- pnpm lint belum lulus karena masalah format lama serta kesalahan parsing pada dokumen contoh docs/keasramaan.html dan docs/rapor.html. Tidak dilakukan pemformatan massal pada berkas di luar lingkup rilis.
- Audit dependensi paket Windows masih melaporkan 11 temuan (2 moderate, 9 high, 0 critical), terutama pada rantai dependensi PDF/browser dan Excel. Patch js-yaml dan qs telah diterapkan. Penggantian mayor atau penurunan versi paket tidak dilakukan otomatis karena dapat merusak ekspor PDF/Excel. Rilis ini tidak menyatakan seluruh temuan keamanan sudah selesai.
- Installer belum ditandatangani dengan sertifikat code-signing tepercaya sehingga Windows dapat menampilkan peringatan penerbit.

## Artefak

- Installer: KagangaSetup-v2.2.1.exe.
- Checksum SHA-256 disertakan sebagai KagangaSetup-v2.2.1.exe.sha256 pada GitHub Release.
- Kode sumber rilis berada pada tag v2.2.1 dan cabang codex/release-v2.2.1. Cabang main yang memiliki riwayat berbeda tidak ditimpa paksa.
