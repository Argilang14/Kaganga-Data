# Buku Tamu

Buku Tamu menyimpan kunjungan secara terpisah untuk setiap sekolah.

- Bagikan tautan publik kepada petugas penerima tamu.
- Aktifkan passkey bila formulir hanya boleh digunakan di lingkungan sekolah.
- Mengganti tautan akan langsung menonaktifkan tautan lama.
- Gunakan filter tanggal sebelum mengekspor Excel atau mencetak PDF.
