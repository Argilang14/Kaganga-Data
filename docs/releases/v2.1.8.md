# Kaganga v2.1.8

Tanggal rilis: 15 September 2026

## Perbaikan penting

- Memperbaiki paket v2.1.7 yang terkompilasi dari staging lama.
- Pipeline installer sekarang selalu menjalankan build dan menyiapkan staging baru sebelum Inno Setup.
- Seluruh fitur v2.1.7 kini disertakan dalam paket, termasuk RPM, lampiran pembelajaran, dashboard harian, Cetak Dokumen, Cetak Raport, dan pengamanan impor-ekspor.

## Catatan pembaruan

1. Pengguna v2.1.7 disarankan memperbarui ke v2.1.8.
2. Installer mempertahankan `AppId` Kaganga dan memperbarui instalasi yang sama.
3. Port aplikasi tetap `1206` dan data tetap berada di `%LOCALAPPDATA%\Kaganga-data`.
4. Backup database dibuat sebelum migrasi versi baru.
5. Data sekolah tidak disertakan dalam installer dan tidak ditimpa saat pembaruan.

## Validasi rilis

- Isi staging diverifikasi memiliki rute RPM dan seluruh rute baru sebelum installer dikompilasi.
- Tes regresi, pemeriksaan Svelte, build produksi, kesehatan database installer, dan startup paket staging dijalankan sebelum publikasi.
