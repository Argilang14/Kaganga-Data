# Kaganga v2.2.5

Tanggal persiapan: 10 Oktober 2026.

## Perubahan

- Dashboard umum dan pimpinan digabung. Ringkasan pengawasan tetap mengikuti izin akun, kelas, dan semester aktif; tautan dashboard pimpinan lama tetap berlaku.
- Dashboard menampilkan pegawai aktif, ringkasan sekolah/sholat/makan, kelengkapan data, pengawasan per kelas, dan prestasi akademik berdasarkan nilai rapor semester. Kehadiran konsisten hanya memakai masuk sekolah, bukan sholat atau makan.
- Sekolah Rakyat Terintegrasi dapat mengatur nama resmi dan NPSN SD/SMP/SMA melalui Satuan Pendidikan tanpa memisahkan server, database, atau QR murid. Pemetaan kelas, kop dokumen, sesi ujian, konfigurasi dan pratinjau Dapodik mengikuti satuan terkait.
- Form sekolah SRT mengarahkan pengaturan NPSN ke Satuan Pendidikan. Identitas dokumen ujian yang sudah diterbitkan tetap disimpan sebagai snapshot.
- Monitoring dan Rekap menjadi halaman terpisah dalam satu dropdown. Rekap mendukung Semua Kelas sesuai hak akses, termasuk ekspor Excel.
- Tab Asrama memuat Berangkat dari Asrama, Tiba di Asrama, dan Apel Malam. Monitoring membandingkan keberangkatan asrama dengan kedatangan sekolah, serta kepulangan sekolah dengan kedatangan asrama.
- Sakit/izin hanya melengkapi tampilan pasangan perjalanan yang belum tercatat. Catatan nyata tidak ditimpa, belum tercatat tidak dianggap alfa, dan keberangkatan tidak otomatis menjadi kedatangan. Rekap tetap memakai catatan sumber masing-masing.
- Untuk sementara, Wali Asrama dapat mengabsen semua murid aktif di sekolah dan semester aktif tanpa penugasan murid/kelas: manual, massal, scan QR, Monitoring, rekap, dan ekspor. Wali Asuh tetap sesuai penugasan.
- Wali Asrama boleh membaca foto untuk identifikasi absensi. Perubahan foto, nilai/data murid di luar absensi, pengaturan, impor, pengelolaan QR, dan koreksi tanggal lama tidak dibuka otomatis. Tanggung jawab kegiatan sekolah/asrama tetap dibatasi.
- Tampilan dashboard dan Monitoring dirapikan untuk desktop, tablet, dan HP. Ringkasan Sekolah & Asrama menjadi statistik berwarna yang dapat difilter, dengan kolom pemantauan, status, perjalanan, dan tabel yang lebih teratur.

## Pemasangan dan Migrasi

1. Buat backup database di PC server sekolah dan salin folder foto/lampiran sebelum memperbarui. Backup pengembang bukan pengganti backup PC sekolah.
2. Unduh `KagangaSetup-v2.2.5.exe` melalui Pengaturan > Cek Update atau Releases. Tutup Kaganga lama sebelum memasang di lokasi instalasi yang sama.
3. AppId dan lokasi data tetap sama. Installer baru membawa database awal bersih, bukan data sekolah pengembang. Migrasi kompatibilitas dijalankan saat startup tanpa menghapus data lama.
4. Untuk SRT, periksa nama/NPSN tiap jenjang serta pemetaan kelas di Satuan Pendidikan sebelum mencetak dokumen atau menambahkan peserta ujian baru.
5. Periksa akun, daftar murid, dashboard, Catat Absensi, Monitoring Asrama, rekap, dan pratinjau PDF setelah pemasangan. Atur jam kegiatan asrama sesuai jadwal sekolah.
6. Untuk rollback, pulihkan backup database dan foto/lampiran sebelum menggunakan installer sebelumnya. Jangan menghapus database untuk menangani kegagalan pembaruan.

Source rilis tersedia pada branch utama. Pengguna installer tidak perlu clone ulang. Untuk pengembang:

```bash
gh repo clone Argilang14/Kaganga-Data
```

## Pengujian dan Batasan

- Unit test: 241 lulus. Pemeriksaan Svelte: 0 error, 115 warning yang masih perlu ditindaklanjuti. Build produksi dan ESLint terarah pada modul inti perubahan lulus.
- QA monitoring/dashboard: 30 kelompok pemeriksaan lulus, termasuk hak akses, integrasi Sekolah-Asrama, rekap Semua Kelas, dan tampilan desktop/tablet/HP (320 sampai 1366 piksel).
- QA satuan pendidikan serta identitas/arsip murid lulus: pemetaan kelas, snapshot dokumen, penomoran ujian, QR lintas jenjang, impor/ekspor, kenaikan kelas, dan pemeriksaan integritas SQLite.
- Runtime paket v2.2.5 lulus untuk database awal bersih dan upgrade salinan database lama, termasuk migrasi, alur autentikasi, integritas, foreign key, dan halaman utama. Data lama tidak dihapus pada pengujian upgrade.
- Semua perubahan data QA memakai salinan database dan port terisolasi. PC sekolah dan port produksi 1206 tidak dioperasikan. Database, backup, unggahan, token, dan screenshot sekolah tidak diterbitkan ke repo.
- Installer belum ditandatangani dengan sertifikat penerbit tepercaya. Windows dapat menampilkan peringatan penerbit.
- Lint seluruh repo masih memiliki masalah lama pada dokumen HTML dan pemformatan. Tidak dilakukan refaktor/pemformatan massal untuk rilis ini.
- Audit dependensi produksi masih melaporkan 12 kerentanan: 1 rendah, 2 sedang, dan 9 tinggi, terutama pada rantai PDF/browser dan Excel. Rilis ini belum menyelesaikan seluruh temuan keamanan dependensi; pembaruan dependensi membutuhkan pengujian kompatibilitas tersendiri. Jangan menganggap hasil QA fungsional sebagai jaminan bebas kerentanan.
- Belum ada persetujuan sakit/izin, surat otomatis, monitoring kehadiran guru di kelas, atau pengiriman WhatsApp otomatis dari hubungan Sekolah-Asrama.
- Untuk SRT, penerapan data dan pengiriman nilai ke Dapodik masih dinonaktifkan sampai pencocokan ID dipisahkan per satuan. Sekolah non-SRT tetap mengikuti alur lama. NIS yang sama antarjenjang dalam satu semester belum didukung; konflik impor tidak boleh diabaikan.
