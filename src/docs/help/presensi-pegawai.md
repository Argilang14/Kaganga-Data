# Presensi Pegawai

Presensi Pegawai menggunakan data aktif dari menu Data Pegawai, bukan dari akun pengguna.

- Mode Harian digunakan untuk mengisi hadir, izin, sakit, dinas luar, atau cuti.
- Isi Sekaligus hanya memproses pegawai pada halaman yang sedang terlihat.
- Mode Bulanan menampilkan rekap per tanggal dan jumlah setiap status.
- Dinas Luar yang telah disetujui otomatis tampil sebagai status Dinas Luar.
- Jadwal hari sekolah dan hari libur mengikuti Pengaturan Presensi pada Data Rapor.
