# Kaganga v2.2.2 Beta 1

Versi teknis dan tag: `2.2.2-beta.1` / `v2.2.2-beta.1`.
Tanggal persiapan: 4 Oktober 2026.

## Perubahan

- Menu Kartu Ujian dan Kartu Ujian Meja digabung. Tombol meja ON memakai delapan kartu 94 x 62 mm per A4; OFF memakai empat kartu 94 x 123 mm per A4.
- Opsi kartu ujian berwarna hijau saat ON dan netral saat OFF. Pilihan lama kartu meja tetap dapat dibuka. PDF tampil pada preview dan dibersihkan saat pilihan berubah.
- Perbaikan identitas murid untuk NISN kosong, placeholder, atau duplikat agar status satu murid tidak menyembunyikan murid lain. Tersedia audit dan peninjauan identitas yang bermasalah.
- Penyelarasan akses jabatan pimpinan, guru, wali kelas, wali asuh, dan wali asrama dengan izin serta lingkup murid masing-masing.
- Pembuatan akun pegawai massal dan pengeditan penugasan kelas/mata pelajaran pada akun yang sama.
- Scan QR kegiatan dimulai dengan Pilih kegiatan; kegiatan wajib dipilih sebelum pemindaian dimulai.
- Ringkasan kehadiran untuk WhatsApp per kelas, jenjang, atau seluruh jenjang sesuai hak akses. Nama murid sakit, izin, izin pulang, alfa, dan belum tercatat mengikuti sumber data absensi. Pengiriman tetap dikonfirmasi pengguna, bukan pengiriman otomatis ke grup.

## Migrasi dan pemasangan

1. Beta adalah versi pengujian. Uji pada salinan data sekolah sebelum pemasangan ke server utama.
2. Buat backup database pada PC server sekolah, lalu salin folder foto dan lampiran. Backup pada laptop pengembang bukan pengganti backup PC sekolah.
3. Tutup Kaganga lama dan pasang `KagangaSetup-v2.2.2-beta.1.exe` pada lokasi aplikasi sebelumnya.
4. AppId serta folder aplikasi dan data Kaganga tetap sama. Installer membawa database kosong untuk instalasi baru, bukan data sekolah pengembang.
5. Startup menjalankan penyesuaian skema yang diperlukan. Jangan mengganti database lama dengan database bawaan installer atau mengimpor Excel sebagai pemulihan tanpa audit.
6. Periksa daftar murid aktif/arsip dan hasil peninjauan identitas. Data PC sekolah tidak dipulihkan dari laptop pengembang secara otomatis.
7. Periksa penugasan dan izin pengguna, pilih kegiatan sebelum scan, lalu uji ringkasan absensi serta preview kartu ujian.
8. Jika perlu kembali ke versi stabil, hentikan aplikasi dan pulihkan pasangan backup database serta berkas sebelum upgrade. Jangan sekadar menjalankan aplikasi lama terhadap skema baru.

Rilis stabil `v2.2.2` tidak ditimpa. Beta diterbitkan sebagai prerelease, tidak dijadikan latest, dan diunduh manual dari GitHub. Kode beta menjadi snapshot terbaru pada main; instalasi pengguna tidak berubah hanya karena main diperbarui.

## Batasan

- Installer belum ditandatangani dengan sertifikat penerbit tepercaya; Windows mungkin menampilkan peringatan.
- Pengujian runtime fresh/upgrade terisolasi tidak menggantikan pengujian wizard pada PC/VM lain.
- Peringatan Svelte serta masalah format/lint lama dicatat terpisah; rilis ini tidak merombak seluruh berkas contoh.
- Database, backup, kredensial, foto, lampiran, dan log QA tidak boleh masuk commit maupun artefak publik.

## Hasil validasi

- 165 unit test lolos, tanpa kegagalan.
- `pnpm check`: 0 error, 115 peringatan lama pada 35 berkas.
- Build produksi dan staging Windows lolos.
- QA identitas murid: migrasi UID, peninjauan, arsip satu/massal, pemulihan, impor transaksional, kenaikan kelas, ekspor nol awal NISN, penolakan duplikat, dan izin lintas sekolah lolos.
- QA hak akses/absensi: pimpinan, guru, wali kelas, wali asuh, wali asrama, lingkup murid, QR wajib kegiatan, status manual, ringkasan WhatsApp, audit perubahan, dan tampilan desktop/tablet/HP lolos.
- QA akun massal serta edit penugasan: pratinjau, login pertama/ganti sandi, dua kelas/mapel, rollback transaksi, pembatasan lintas sekolah, dan audit tanpa sandi lolos.
- QA kartu ujian: dua format, filter, pagination, nama file, ON/OFF hijau/netral, tautan lama, invalidasi preview, preferensi QR, dan tampilan desktop/tablet/HP lolos.
- Paket runtime fresh serta upgrade dari backup lokal sebelum v2.2.2 lolos pada port 5160/5161. Jumlah data terjaga, integrity_check OK, dan foreign_key_check bersih.
- Pemeriksaan 129 berkas source yang disiapkan untuk commit tidak menemukan database, backup, direktori upload, pola token GitHub, atau private key. Database installer kosong dari sekolah, kelas, murid, pegawai, sesi dan peserta ujian.
- `pnpm lint` penuh belum lolos akibat format lama serta parsing dua dokumen HTML contoh. Tidak dilakukan format massal di luar lingkup rilis.
- Audit dependensi paket Windows: 11 temuan (2 moderate, 9 high, 0 critical). Perbaikan dependensi perlu audit terpisah; beta tidak disarankan langsung dibuka ke internet atau dipasang massal tanpa pengujian.

Semua QA memakai salinan database dan port terisolasi. PC sekolah, port 1206, dan pengiriman WhatsApp nyata tidak dioperasikan. Backup lokal beserta manifest lampiran tersedia sebelum rilis; foto/lampiran PC sekolah tetap harus dibackup langsung pada PC tersebut.
